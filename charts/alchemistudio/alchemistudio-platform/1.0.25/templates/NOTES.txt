────────────────────  AI GUARDRAILS — OFF BY DEFAULT  ────────────────────
  The AI-safety tier (PII / secret-detection / jailbreak / toxicity / topical /
  content-filter) is DISABLED by default to keep this first install fast and light.
  Enable it any time — on its OWN upgrade, not during the first install:

    CLI:  helm upgrade {{ .Release.Name }} alchemi/alchemistudio-platform \
            --reuse-values --set guardrails.enabled=true --wait --timeout 30m
    UI:   flip "Enable AI guardrails" in the form → Upgrade

  It adds 6 services (~2.2 CPU / 6.6Gi) and pulls several GB of model images.

──────────────────  IF AN INSTALL/UPGRADE TIMES OUT  ────────────────────
  Heavy image pulls can exceed Rancher's default 10-minute timeout, leaving the
  release stuck ("another operation in progress"). To avoid it:
    • Rancher UI: tick "Customize Helm options" → set Timeout = 1800 (30 min),
      or uncheck "Wait".
    • CLI:        helm install ... --wait --timeout 30m

  Trial runs in fixed-seats mode (no license needed). Production (your own
  registry, a license, scale): support@alchemistudio.ai
